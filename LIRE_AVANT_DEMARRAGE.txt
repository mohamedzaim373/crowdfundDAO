INSTALLATION
1. Extraire completement le ZIP.
2. Installer Node.js 22.13 ou plus recent (et Python 3 pour le bonus).
3. Ouvrir un terminal dans ce dossier, a cote de package.json.
4. Executer :
   npm ci
   npm run check

LANCEMENT LOCAL
Terminal 1 : npm run node
Terminal 2 : npm run deploy:local
             npm run demo:local
Terminal 3 : npm run keeper:local
Terminal 4 : npm run frontend:dev

Ouvrir http://127.0.0.1:5173
Le deploiement genere automatiquement frontend/.env avec les nouvelles adresses.
Si le noeud est redemarre, refaire le deploiement et relancer le keeper.
Les dossiers node_modules et les environnements Python sont exclus du ZIP.
